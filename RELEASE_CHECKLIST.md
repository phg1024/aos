# AOS Sharing Checklist

Use this checklist before publishing a milestone, asking for review, or sharing the repo snapshot with someone new.

- Working tree reviewed and intentional
- `make test` passes
- README reflects the current project scope and commands
- `STATUS.md` reflects the current prototype state
- Generated live-run outputs are removed from version control unless intentionally curated
- Scratch binaries, transcripts, and one-off experiment files are ignored
- Reports included in git are durable reference artifacts, not transient run state
