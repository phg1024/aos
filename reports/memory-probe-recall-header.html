Memory Evaluation: A1 Re-Test with Fair-Share Header Rendering

The A1 follow-up (memory-probe-recall-fix.html) found that the header showed agent indexes newest first within 6 KB, so the oldest round-2 index became a bare pointer in every draw. aos code changed the header in 6c55bdb: the 6 KB budget is now shared by whole lines, round by round, oldest segment first, and each index shows its first lines plus a "(+K more lines ...)" pointer. This re-test froze a new plan on that runtime (d9e653e): 27 fresh handoffs, 23 new unrecorded-fact probes written blind before any index existed, plus the 11 frozen probes, 9 answers per arm, graded blind by hand.

Primary result, significant: on the 23 new probes A1 gave the main fact in 177 of 207 answers (85.5%) against 146 of 207 (70.5%) for C (RecallOff). Difference +31, two-sided stratified permutation test p < 0.0001 (no permutation of 100,000 reached it).

  • The gain sits where the index says the fact: on the 16 probes a shown line states in some draw, 128/144 vs 96/144 (+32); on the other 7, 49/63 vs 50/63 (−1). A1 answers whose own draw's header showed a stating line: 93 of 96 right; stating line hidden: 8 of 15.
  • All three draws scored the same: 59 of 69 each.
  • The follow-up's blind spot is fixed: r2-verify-dir 9/9 vs 0/9 (follow-up 1/9 vs 1/9); r5-register-counts 8/9 vs 0/9 (follow-up 4/9 vs 0/9).

Harm check, no regression: on the 8 recorded and recorded-wrong probes, main 68/72 vs 65/72 (Fisher p = 0.53), contra 18/72 vs 20/72 (p = 0.85); no probe flagged. Of the 74 A1 answers graded contra (46 new, 28 frozen; C had 69 + 45), 13 took the wrong statement from a shown index line: 7 from three lines that misstate their own range, 6 from lines that faithfully copy the agent's own wrong note (r5-tir-guard, where A1 still repeated the wrong entry less than C, 4/9 vs 8/9). 27 more were plausibly misled by a line that leaves a detail out.

Cost: on the new probes A1 used fewer tokens (88.8K vs 116.2K per answer), fewer model calls (2.5 vs 3.1) and read half the bytes; the header carries about 5.2 KB of index. The 27 handoffs cost 4.94M tokens (183K each).

What Was Run

  • Runtime: 6c55bdb (fair-share header), merged into this branch. Binaries built from the freeze commit d9e653e (run.log stamps hash 6e5368ca719e). The header's agent-index budget is pinned to 6144 bytes in every handoff, probe and header check (--header-index-bytes 6144); every A1 sample records agent_index_budget = 6144.
  • Model: qwen3.8-flash-next-nvfp4-nvfp4 via the OpenAI-compatible endpoint phg-gpu.local:8080 (server behind it not recorded), temperature 0.6, top-p 0.95, 64K context, as in the earlier runs.
  • Arms: C = own memory, RecallOff; A1 = own memory with recall a1 and the agent-written indexes of one draw. 9 answers per arm per probe; A1 takes 3 from each draw.
  • Probes: 23 new unrecorded facts (11 first pass, 12 second pass; selection.md), written and frozen before any index existed; plus the 11 frozen own-memory probes (3 unrecorded, 6 recorded, 2 recorded-wrong).
  • Grading: every answer hand-graded main / exact / contra by eight reader agents with the rubric, the archive and the checkpoint's working memory and live history, blind to arm (answers shuffled with Random(20261031), arm, draw and reads stripped; grading/BRIEF.md). Grades were committed (5f6d7ef) before the key was opened.
  • Run: 612 answers (207 + 99 per arm), none with a backend error; finished 2026-10-31T06:41Z.

Deviations, disclosed

  • G1 failed, so the draws were re-made. 6c55bdb changed how an index line holding several entries is parsed. The first freeze (6d49bf7) re-ran all 27 handoffs as its rule says. aos book asked, in a message that crossed it, to stop and report first; the run was stopped at 00:27:25 UTC, before any handoff step finished. aos book then chose the rule as written (option b), with the budget pinned and index recall graded on the new draws.
  • Two harness bugs, fixed before any probe was asked. Seven new probes' regex patterns used (?!\d), which Go's regexp rejects, so the probe file did not load; each became (?:\D|$), which matches the same texts (probe file 5af3f5b442bb → e894f218de67; only expect changed, and the regex score is secondary). The stop-rule check had a Python 3.10 syntax error and was rewritten. No Go code changed; the probe phase resumed only after checking that the gates had passed.

For aos code

  • First lines are not the same as the important lines. Under the 6 KB budget, the round-2 checkpoint hides an index's last lines. h-414-1's truth (#56) and h-557-3's (#167 in d2/d3) sat in hidden lines; A1 was no better than C on the first and worse on the second. Choosing which lines to show (e.g. failures and outcomes first, or spreading the shown lines across the range) may matter more than the budget.
  • Index lines drop qualifiers. "93.37/96.61" without "best", "transform_mesh missing from rewrite" without the file, "round-7" added where the source has no round. The handoff prompt could ask for the file, the unit and the measure for each number, and forbid attributions the range does not contain.
  • An index faithfully preserves the agent's own wrong conclusions (r5-tir-guard). That is the working memory's problem too; an index line marked as the agent's conclusion, not an observation, might help.

Caveats

  • One run of one task (pathtracer-bunny-phase3), one model, three checkpoints. The probes are facts this agent did not record; whether the gain holds on other tasks is untested.
  • The unit of the primary test is the probe, but the 23 probes cluster in 9 segments and 3 checkpoints, and the three draws come from the same handoff prompt.
  • Graders differ in strictness on side details: some counted a wrong round, a wrong cited source or a miscount as contra, others did not. Blindness means this falls on both arms alike, but contra and exact counts are less stable than main. Main is the primary measure.
  • The graders saw the probe notes, which state the truth and where it is recorded; they did not see arms, draws, reads or headers.
  • The index-blame review was done after unblinding (it concerns A1 only) by two reader agents; its "partly" category is a judgment call.
