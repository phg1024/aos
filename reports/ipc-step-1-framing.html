IPC Step 1: Framing

This is step 1 of the slice in ipc-design.md, for defect B5. A peer could make its text look like the runtime's own lines, through mail, through a file its reader looks at, or through a delegated child's final message. Now it cannot imitate those lines.

Result:

  • Probe B5 now asserts, and passes. Against the source before this step, all three of its cases fail.
  • Package tests, vet, and the ipc and supervision audits pass.
  • A record made by v0.1.4 source, and eval's three ca78ad9 trials (31/31, 8/8, 9/9), replay identically.

The limit: this stops imitation, not persuasion. A model can still follow what it reads. Capabilities are what bound a persuaded agent, and no message changes them.

Steps 2 to 5 are not built. B8c and B11 are still open.

Line breaks. In mail, these all become \n before marking: \r\n, \r, \v, \f, U+001C–U+001E, U+0085, U+2028 and U+2029. Other control characters are written out visibly. The escape in other turns finds line starts with the same set and leaves the bytes alone.

2. Where the Escape Is Applied

At render. PromptBackend.promptContent applies it on the way to the model.

Holds the raw textHolds the escape
Session history, checkpoints, memory segments, read_memory, search_memory, aos inspect, the tool's artifact, the file itselfThe prompt, and the request log, which records what the model was sent and is what replay compares

Why: the records are the evidence of what a tool returned. The exception: peer mail is framed when it enters the history, and its raw body stays in the mailbox_message artifact.

3. edit_file

Content is byte-identical in the prompt unless a line begins with a reserved opener. For a file line runtime notice: x, shown as \runtime notice: x:

old_textWhat happens
runtime notice: xMatches, as any line does
\runtime notice: x, copiedThe exact text is tried first and finds nothing. Then old_text and new_text are unescaped and it matches. The output says unescaped: true.
\runtime notice: x, and the file really holds thatThe exact match wins, and the backslash stays

write_file is not unescaped. A model that rewrites a whole file and keeps the backslash writes it. The system prompt tells it to leave the backslash out.

4. One List of Openers

  • Every runtime-written entry goes through runtimeNote(role, opener, text), and only internal/framing can make an opener.
  • ReservedPrefixes() is derived from that table, and an AST test fails on any entry built another way.
  • It has already paid off: the design's table missed budget steps=, budget time= and budget tokens=. Building the constructor exposed them.

6. Changed for Existing Runs

  • The system prompt gains one sentence of 361 bytes, so a run's first request has a new cache prefix. Recall-off probe arms are held byte-identical (TestRecallOffKeepsThePromptsAsBefore), and memory probes start from those arms.
  • A peer's message reads differently.
  • A later line of a runtime-written turn that begins with a reserved opener reaches the model with a backslash.
  • Bus.Send("user", …) and Bus.Publish("user", …) are refused.
  • edit_file may match through the backslash, and its output may have unescaped.
  • Bus.Publish and Bus.Subscribe refuse a topic that is not one plain line of at most 128 bytes.
  • run.started has peer_framing: v2. Older records replay under the old rendering and report legacy_peer_framing.

7. Known Limits and One Finding

  • The escape is textual, and only exact forms are in scope: another case (RUNTIME NOTICE:), markup in front (> runtime notice:) and look-alike letters pass in a tool result. Case and markup variants read as quotes or text, not as the runtime's form. Mail has no such gap, since every line is marked.
  • Common text can match: a changelog line [#12] fix is shown escaped.
  • Unchanged: working memory and segment indexes, a delegated goal, and a delegator's answer, which reaches a child as a user turn.
  • unconfined_run bypasses the protected state directory, so such an agent can still write the bus.
  • Finding: a run with mail has never replayed identically. A message's timestamp is the wall clock's, and its record holds it. Every request matches (TestReplayOfMailMatchesEveryRequest), and then the artifact comparison diverges. The replay bus in decision 11 would remove this.
