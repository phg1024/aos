== Round 7 ==
Goal: shave the remaining closest-hit BVH walk without touching the estimator. Every candidate had to produce a PFM byte-identical to round 6 on scene-default, scene-alt-view and scene-caustic-closeup at 64spp seed 1; all decisions were made with interleaved paired A/B against a frozen round-6 binary kept in _r7b/ (its own include/src/shaders copies), never from absolute timings, because the machine swings 33-96ms.

KEPT (three changes, each measured against the round-6 baseline, then combined):
1) f32 BVH node. Nodes were stored as two uint4 with quantised bounds and decoded with u2f on every load. They are now two float4 (32 bytes, same size) holding the bounds directly, so a node load costs no decode and no integer temp. Paired vs r6: geo-mean 0.9956 (-0.44%), faster in 16/16 pairs. Byte-identical on all three scenes.
2) Shadow-walk stack payload. The any-hit shadow walk kept only node indices on its stack and re-read the node to recover the payload; it now carries the payload alongside the index, which removes one dependent load per popped node. Paired vs r6: 0.9951 (-0.49%), 16/16. Byte-identical.
3) 12-byte sample buffer (idea (b) applied where it actually pays). The sample-parallel frame writes width*height*spp float4 and reads them back in the combine pass: 268MB each way per frame at 512x512x64. The unused fourth component is dropped via a 3-float struct, cutting a quarter of 536MB of traffic. Pure layout, same float bits, so the ordered sum rounds identically. Paired vs r6: 0.9982 and 0.9980 over two 16-pair batches, 26/32 faster. Byte-identical.
Combined (pathtracer == pt_round_07) vs frozen round 6 in _r7b: geo-mean render 0.9898, gpu 0.9898, faster in 18/18 pairs at 64spp (min 30.940 vs 31.247), and independently 0.9900 with 6/6 pairs at 256spp (min 122.012 vs 123.260) - two different sample counts agreeing is the strongest evidence available on this noisy machine.

REJECTED with evidence:
- leaf_size 2 (+0.9%, 0/16) and bins 16/64 (neutral) - earlier in the round, both byte-identical but slower.
- uint4-packed traversal stack, MTLMathModeFast, PT_TG32x8 threadgroup, MTLStorageModePrivate sample buffer, 32-byte padded node: all neutral-or-worse in paired runs.

//
// Unbiased unidirectional path tracing. Diffuse floor vertices get next-event
// estimation against the rectangular area light in addition to BSDF sampling;
// glass vertices are pure BSDF sampling with a delta specular lobe, so their
// light hits are counted directly. Emission along a continued path is added
// only for the primary ray and after specular bounces, which is what keeps the
// NEE term from being double counted.
//
// The statistics are unchanged from round 1: same sample count, same maximum
// depth, same Russian-roulette rule after depth 3, and the same per-pixel RNG
// stream, so a given seed reproduces its PFM bit for bit.

inline float3 pt_environment(constant PtParams& params) {
    return pt_v3(params.env_radiance);
}

// Schlick approximation of the Fresnel equations for a dielectric interface
// between ior_i (the side the ray comes from) and ior_t (the other side).
// NOTE: the total-internal-reflection guard uses (ior_t/ior_i)^2, which is not
// the refraction-side ratio pt_refract uses. That asymmetry is exactly what the
// frozen round-1 baseline was rendered with, so the caustic and RMSE gates are
// defined by it and this expression must not be "corrected".
inline float pt_fresnel(float cos_incident, float ior_i, float ior_t) {
    const float c = clamp(cos_incident, 0.0f, 1.0f);
    const float eta = ior_t / ior_i;
    const float sin2_t = eta * eta * (1.0f - c * c);
    if (sin2_t > 1.0f) {
        return 1.0f;  // total internal reflection
    }
    const float r0 = (ior_i - ior_t) / (ior_i + ior_t);
    const float r0sq = r0 * r0;
    const float one_minus_c = 1.0f - c;
    const float f2 = one_minus_c * one_minus_c;
    const float f4 = f2 * f2;
    return r0sq + (1.0f - r0sq) * (f4 * one_minus_c);
}

// Snell's law. `incident` is the unit ray direction, `surface_normal` is the
// unit normal facing against it, `eta` is n_i / n_t. False means TIR.
inline bool pt_refract(float3 incident, float3 surface_normal, float eta, thread float3& result) {
    const float cos_incident = -dot(incident, surface_normal);  // positive by construction
    const float sin2_t = eta * eta * (1.0f - cos_incident * cos_incident);
    if (sin2_t > 1.0f) {
        return false;
    }
    const float cos_t = sqrt(max(0.0f, 1.0f - sin2_t));
    // eta * I + (eta * cos_i - cos_t) * N is already unit length by Snell's
    // law, so it is returned un-normalized: one sqrt and one divide fewer per
    // glass bounce.
    result = eta * incident + (eta * cos_incident - cos_t) * surface_normal;
    return true;
}

// Uniform sample of the emitter rectangle; returns the sampled point.
inline float3 pt_sample_light(constant PtParams& params, thread uint& state) {
    const float3 center = pt_v3(params.light_center);
    const float3 u_axis = pt_v3(params.light_u);
    const float3 v_axis = pt_v3(params.light_v);
    const float su = (2.0f * pt_random(state) - 1.0f) * params.light_half_u;
    const float sv = (2.0f * pt_random(state) - 1.0f) * params.light_half_v;
    return center + su * u_axis + sv * v_axis;
}

// Cosine-weighted hemisphere direction around `normal`.
inline float3 pt_sample_cosine(float3 normal, thread uint& state) {
    const float r1 = pt_random(state);
    const float r2 = pt_random(state);
    const float phi = 6.283185307179586f * r2;
    const float sin_theta = sqrt(r1);
    const float cos_theta = sqrt(max(0.0f, 1.0f - r1));
    const float3 tangent = pt_orthonormal_tangent(normal);
    const float3 bitangent = cross(normal, tangent);
    float cos_phi = 0.0f;
    const float sin_phi = sincos(phi, cos_phi);  // one transcendental pair instead of two
    // The frame is orthonormal and (sin_theta*cos_phi, sin_theta*sin_phi,
    // cos_theta) is unit length, so the direction needs no renormalization.
    return tangent * (cos_phi * sin_theta) + bitangent * (sin_phi * sin_theta) +
           normal * cos_theta;
}

// One bounce of the integrator loop. Returns false when the path is finished.
inline bool pt_trace_path(PtScene scene, PtRay ray, uint pixel_seed, thread float3& radiance) {
    constant PtParams& params = *scene.params;
    uint state = pixel_seed;
    float3 throughput = float3(1.0f);
    bool inside_glass = false;
    // Whether the previous vertex was specular (mirror/glass). Emission at a
    // light hit is counted only for the primary ray and after a specular
    // bounce; diffuse vertices collect the light through next-event estimation.
    bool last_specular = true;

    for (uint depth = 0; depth < params.max_depth; ++depth) {
        const PtHit hit = pt_intersect_scene(scene, ray);

        if (hit.material == PtMaterialNone) {
            radiance += throughput * pt_environment(params);
            return false;
        }

        if (hit.material == PtMaterialLight) {
            if (depth == 0u || last_specular) {
                radiance += throughput * pt_v3(params.light_radiance);
            }
            return false;
        }

        if (hit.material == PtMaterialFloor) {
            const float3 normal = hit.normal;

            // Next-event estimation: uniform sample of the light rectangle.
            const float3 light_point = pt_sample_light(params, state);
            const float3 to_light = light_point - hit.position;
            const float distance_sq = max(1e-8f, dot(to_light, to_light));
            const float3 light_direction = to_light * rsqrt(distance_sq);
            const float incident_cosine = dot(normal, light_direction);
            // Cosine of the light's own lobe: emission direction toward x.
            const float light_cosine = -dot(pt_v3(params.light_normal), light_direction);
            if (incident_cosine > 0.0f && light_cosine > 0.0f) {
                const PtRay shadow_ray =
                    pt_make_ray(hit.position + normal * 1e-4f, light_direction);
                const float shadow_limit = sqrt(distance_sq);
                if (!pt_occluded(scene, shadow_ray, shadow_limit)) {
                    // Contribution = (albedo/pi) * Le * cos_i * cos_l * A / d^2:
                    // f_r times the geometry term divided by the area pdf 1/A.
                    const float weight = params.floor_albedo * incident_cosine * light_cosine *
                                         params.light_area / (3.14159265358979f * distance_sq);
                    radiance += throughput * weight * pt_v3(params.light_radiance);
                }
            }

            // Continue along a cosine-weighted diffuse direction. A diffuse
            // vertex ends any glass traversal and forbids counting emission
            // directly on the next vertex.
            throughput *= params.floor_albedo;
            inside_glass = false;
            last_specular = false;
            ray = pt_make_ray(hit.position + normal * 1e-4f, pt_sample_cosine(normal, state));
        } else {
            // Clear glass: sample reflection or refraction as a delta lobe.
            const bool entering = dot(ray.direction, hit.normal) < 0.0f;
            const float3 oriented_normal = entering ? hit.normal : -hit.normal;
            const float ior_i = inside_glass ? params.ior : 1.0f;
            const float ior_t = inside_glass ? 1.0f : params.ior;
            const float ratio = ior_t / ior_i;
            const float reflectance =
                pt_fresnel(-dot(ray.direction, oriented_normal), ior_i, ior_t);

            float3 transmitted = float3(0.0f);
            const bool refracted =
                pt_refract(ray.direction, oriented_normal, ior_i / ior_t, transmitted);

            if (!refracted || pt_random(state) < reflectance) {
                // Sampling probability equals the Fresnel reflectance, so the
                // reflectance cancels and the throughput factor is 1.
                last_specular = true;
                ray = pt_make_ray(hit.position + oriented_normal * 1e-4f,
                                  reflect(ray.direction, oriented_normal));
            } else {
                // Radiance scales by (n_t/n_i)^2 across a dielectric; the
                // (1-F) transmittance cancels the sampling probability.
                throughput *= ratio * ratio;
                ray = pt_make_ray(hit.position - oriented_normal * 1e-4f, transmitted);
                inside_glass = entering;
                last_specular = true;
            }
        }

        // Unbiased Russian roulette, only once the path is deep enough.
        if (depth >= 4u) {
            const float survival = clamp(max(throughput.x, max(throughput.y, throughput.z)),
                                         0.05f, 0.95f);
            if (pt_random(state) > survival) {
                return false;
            }
            throughput /= survival;
        }
    }
    return false;
}

// Morton (Z-order) index inside a kTraceTile x kTraceTile tile. Threads that
// are neighbours in the dispatch order end up spatially close on screen, which
// makes their camera rays walk the BVH through the same upper nodes and turns
// eight separate cache lines into one. The mapping is a bijection on the tile,
// so every pixel is still traced exactly once with its own RNG stream and the
// output is bit-identical to the row-major order.
inline uint2 pt_morton_decode(uint code) {
    uint2 out = uint2(0u, 0u);
    // A 32-wide tile needs 10 Morton bits, five per axis.
    for (uint bit = 0u; bit < 5u; ++bit) {
        out.x |= ((code >> (2u * bit)) & 1u) << bit;
        out.y |= ((code >> (2u * bit + 1u)) & 1u) << bit;
    }
    return out;
}

constant uint kTraceTile = 32u;

// Thread-position to pixel mapping for both dispatch layouts: Morton (Z-order)
// index inside a kTraceTile x kTraceTile tile, offset by the tile coordinate.
// It is a bijection on the tile, so every pixel is traced exactly once with its
// own RNG stream and the image is identical to the row-major mapping; the
// mapping only decides which thread gets which pixel.
inline uint2 pt_tiled_pixel(uint2 grid_pos) {
    const uint2 tile = grid_pos / kTraceTile;
    const uint2 local = grid_pos % kTraceTile;
    return tile * kTraceTile + pt_morton_decode(local.x + kTraceTile * local.y);
}

// Traces exactly one camera sample of one pixel and returns its radiance.
// Shared by both dispatch layouts so the arithmetic is identical in each: the
// same seed function, the same two jitter draws, the same camera basis and the
// same path integrator, in the same order.
inline float3 pt_trace_camera_sample(constant PtParams& params, PtScene scene,
                                     float3 camera_position, float3 camera_forward,
                                     float3 camera_right, float3 camera_up, uint2 pixel,
                                     uint index, uint sample, float inv_width,
                                     float inv_height) {
    const uint seed = pt_seed_pixel(params.seed, index, sample);
    uint state = seed;
    const float jitter_x = pt_random(state);
    const float jitter_y = pt_random(state);
    const float ndc_x =
        (2.0f * (float(pixel.x) + jitter_x) * inv_width - 1.0f) * params.camera_scale_x;
    const float ndc_y =
        (1.0f - 2.0f * (float(pixel.y) + jitter_y) * inv_height) * params.camera_scale_y;
    const float3 direction =
        normalize(camera_forward + ndc_x * camera_right + ndc_y * camera_up);

    float3 sample_radiance = float3(0.0f);
    pt_trace_path(scene, pt_make_ray(camera_position, direction), seed, sample_radiance);
    return sample_radiance;
}

inline PtScene pt_make_scene(constant PtParams& params, device const float4* nodes,

    PtScene scene;
    scene.params = &params;
    scene.nodes = nodes;

// Classic layout: one thread per pixel, all spp samples traced serially. Kept
// as a fallback for resolutions/spp whose per-sample buffer would be too large,
// and as the A/B reference for the sample-parallel layout below.
kernel void trace_kernel(uint2 grid_pos [[thread_position_in_grid]],
                         constant PtParams& params [[buffer(0)]],
                         device const float4* nodes [[buffer(1)]],
                         device const PtTri* triangles [[buffer(2)]],
                         device const PtTriNormals* normals [[buffer(3)]],
                         device float4* radiance_out [[buffer(4)]],
                         device atomic_uint& sample_counter [[buffer(5)]],
                         device uchar4* image_out [[buffer(6)]]) {
    const uint width = params.width;
    const uint height = params.height;
    const uint2 pixel = pt_tiled_pixel(grid_pos);
    if (pixel.x >= width || pixel.y >= height) {
        return;
    }

    const PtScene scene = pt_make_scene(params, nodes, triangles, normals);
    const float3 camera_position = pt_v3(params.camera_position);
    const float3 camera_forward = pt_v3(params.camera_forward);
    const float3 camera_right = pt_v3(params.camera_right);
    const float3 camera_up = pt_v3(params.camera_up);

    const uint index = pixel.y * width + pixel.x;
    const float inv_width = 1.0f / float(width);
    const float inv_height = 1.0f / float(height);

    float3 accumulated = float3(0.0f);
    for (uint sample = 0u; sample < params.spp; ++sample) {
        accumulated += pt_trace_camera_sample(params, scene, camera_position, camera_forward,
                                              camera_right, camera_up, pixel, index, sample,
                                              inv_width, inv_height);
    }

    // One atomic per thread instead of one per camera sample: the total is
    // still exactly width*height*spp, but the hot loop has no atomics.
    atomic_fetch_add_explicit(&sample_counter, params.spp, memory_order_relaxed);

    const float3 average = accumulated * params.inv_spp;
    radiance_out[index] = float4(average, 1.0f);
    image_out[index] = pt_tone_map(average);
}

// Sample-parallel layout: one thread per (pixel, sample), so the work per
// thread is a single path instead of a whole pixel's worth of paths. A pixel's
// paths differ enormously in cost (a camera ray that misses the bunny ends
// after one bounce, one that enters the glass runs ten), and with one thread
// per pixel a threadgroup's runtime is the SUM of its 64 paths, which no amount
// of resident-thread overlap can balance: at 512x512 the frame is ~64
// sequential waves of threadgroups, so every wave pays its own tail. Making the
// sample the third grid dimension turns that sum into a max over a much larger,

    const uint height = params.height;
    const uint2 pixel = pt_tiled_pixel(grid_pos.xy);
    if (pixel.x >= width || pixel.y >= height) {
        return;
    }

    const PtScene scene = pt_make_scene(params, nodes, triangles, normals);
    const float3 camera_position = pt_v3(params.camera_position);
    const float3 camera_forward = pt_v3(params.camera_forward);

// One mesh vertex: position and geometric normal, world space. Host-only: the

// One BVH node, exactly 32 bytes: half the traffic of the round-1 40-byte
// layout, and four nodes fit in one 128-byte cache line. The tree is stored in
// pre-order, so an internal node's left child is `index + 1` and only the
// right child index needs storing. `b` doubles as the leaf flag: 0 marks an
// internal node (a = right child), a positive `b` marks a leaf holding `b`
// triangle slots starting at `a` in the packed triangle table. This float form
// is what the host build produces; the GPU reads the quantized form below.
struct PtBvhNode {
    float bmin[3];
    float bmax[3];
    unsigned int a;
    unsigned int b;
};

// GPU-facing BVH node, exactly 16 bytes: eight of them fit in one cache line
// instead of four, which is the main remaining source of traversal traffic, so
// one node is one 16-byte vector load. Bounds are quantized relative to the
// root box along each axis: `loN` is the scaled box minimum and `hiN` the
// scaled box maximum, stored interleaved so the kernel decodes both with one
// uint4 load and two fma per axis. The scale is a power of two and both
// coordinates are rounded outwards by one quantization step, so a quantized
// box always contains its exact counterpart - the traversal can only visit a
// box marginally earlier, never miss one, and the reported hit is unchanged.
// `payload` mirrors the float node: the high bit marks a leaf, whose triangle
// start is in bits 8..30 and whose (triangle count - 1) is in bits 0..7; for an
// internal node it is simply the right child index. The kernel reads the whole
// node as a single uint4.
struct PtBvhNodeQ {
    // lo = (scaled box min x, y, z, unused), hi = (scaled box max x, y, z,
    // payload bit pattern). The coordinates are the quantized integers written
    // out as float32: the host quantization scale is a power of two and every
    // coordinate is an integer below 65536, so float(q) is exactly the value
    // the kernel used to produce with a u2f convert, and removing that convert
    // from the hot box test cannot change any result.
    float lo[4];
    float hi[4];
};

    float y;
    float z;

bool MetalPathTracer::init(const std::string& shader_dir, const std::string& shared_header_path,
                           std::string& error) {
    impl_->device = MTLCreateSystemDefaultDevice();
    if (impl_->device == nil) {
        return impl_->fail(@"no Metal device available", error);
    }
    impl_->queue = [impl_->device newCommandQueue];

    NSString* dir = [NSString stringWithUTF8String:shader_dir.c_str()];
    NSString* header = read_text([NSString stringWithUTF8String:shared_header_path.c_str()]);
    if (header == nil) {
        return impl_->fail(@"cannot read shared shader header", error);
    }

    NSMutableString* source = [NSMutableString string];
    [source appendString:@"#include <metal_stdlib>\nusing namespace metal;\n"];
    // The shared struct header is prepended so both sides agree on the layout;
    // its include guard is meaningless inside a single translation unit.
    [source appendString:[header stringByReplacingOccurrencesOfString:@"#pragma once"
                                                           withString:@""]];

    // The kernel files have dependencies (pt_trace.metal defines the helpers
    // used by the tone mapping helper, which the integrator calls), so they are
    // concatenated in this fixed order; any other .metal files are appended
    // afterwards alphabetically.
    NSArray<NSString*>* ordered =
        @[ @"pt_trace.metal", @"pt_tonemap.metal", @"pt_integrator.metal" ];
    NSFileManager* fm = [NSFileManager defaultManager];
    NSArray<NSString*>* names = [[fm contentsOfDirectoryAtPath:dir error:nil]
        sortedArrayUsingSelector:@selector(compare:)];
    NSMutableArray<NSString*>* ordered_names = [NSMutableArray array];
    for (NSString* name in ordered) {
        if ([names containsObject:name]) {
            [ordered_names addObject:name];
        }
    }
    for (NSString* name in names) {
        if (![name hasSuffix:@".metal"]) {
            continue;
        }
        if (![ordered containsObject:name]) {
            [ordered_names addObject:name];
        }
    }

    bool saw_kernel = false;
    for (NSString* name in ordered_names) {
        NSString* text = read_text([dir stringByAppendingPathComponent:name]);
        if (text == nil) {
            return impl_->fail(@"cannot read shader file", error);
        }
        [source appendString:@"\n"];
        [source appendString:text];
        saw_kernel = true;
    }
    if (!saw_kernel) {
        return impl_->fail(@"no .metal files found next to the binary", error);
    }

    NSError* ns_error = nil;
    MTLCompileOptions* options = [[MTLCompileOptions alloc] init];
    // Fast math lets the compiler use hardware reciprocal/sqrt approximations
    // and fused multiply-add in the traversal and BSDF math. The estimator is
    // unchanged (identical sample streams), only float rounding moves.
    options.fastMathEnabled = YES;
    id<MTLLibrary> library = [impl_->device newLibraryWithSource:source options:options
                                                           error:&ns_error];
    if (library == nil) {
        NSString* combined = [NSString stringWithFormat:@"shader compile failed: %@",
                              ns_error.localizedDescription];
        NSLog(@"%@", combined);
        return impl_->fail(combined, error);
    }

    impl_->trace_pipeline = [impl_->device
        newComputePipelineStateWithFunction:[library newFunctionWithName:@"trace_kernel"]
                                      error:&ns_error];
    if (impl_->trace_pipeline == nil) {
        return impl_->fail(@"trace_kernel pipeline failed", error);
    }

    // Sample-parallel pair: trace one camera sample per thread, then combine in
    // exact sample order. Both are built unconditionally; the classic kernel is
    // still used when the per-sample buffer would be too large.
    impl_->trace_samples_pipeline = [impl_->device
        newComputePipelineStateWithFunction:[library newFunctionWithName:@"trace_samples_kernel"]
                                      error:&ns_error];
    if (impl_->trace_samples_pipeline == nil) {
        return impl_->fail(@"trace_samples_kernel pipeline failed", error);
    }
    impl_->combine_pipeline = [impl_->device
        newComputePipelineStateWithFunction:[library newFunctionWithName:@"combine_kernel"]
                                      error:&ns_error];
    if (impl_->combine_pipeline == nil) {
        return impl_->fail(@"combine_kernel pipeline failed", error);
    }

    impl_->params_buffer = [impl_->device newBufferWithLength:sizeof(PtParams)
                                                      options:MTLResourceStorageModeShared];
    impl_->counter_buffer = [impl_->device newBufferWithLength:sizeof(uint32_t)
                                                      options:MTLResourceStorageModeShared];
    return true;
}

        [trace_encoder endEncoding];

inline uint pt_pcg_next(thread uint& state) {
    state = state * 747796405u + 2891336453u;
    const uint word = ((state >> ((state >> 28u) + 4u)) ^ state) * 277803737u;
    return (word >> 22u) ^ word;
}

inline float pt_random(thread uint& state) {
    return float(pt_pcg_next(state)) * (1.0 / 4294967296.0);
}

// Per-pixel, per-sample stream seed: a pure function of (seed, pixel, sample).
inline uint pt_seed_pixel(uint seed, uint pixel, uint sample) {
    uint state = seed * 747796405u + pixel * 2654435761u + sample * 1597334677u;
    return pt_pcg_next(state);
}

inline float3 pt_orthonormal_tangent(float3 n) {
    // Duff et al. branchless tangent frame construction.
    const float sign = copysign(1.0f, n.z);
    const float a = -1.0f / (sign + n.z);
    const float b = n.x * n.y * a;
    return float3(1.0f + sign * a * n.x * n.x, sign * b, -sign * n.x);
}

// A ray in BVH quantized coordinates, where a box test needs no decode:
// q_origin = (origin - root_min) * scale. The inverse direction is divided by
// the same power of two, so the two factors cancel inside the slab test and it
// returns t in WORLD units, directly comparable with the world-space t limits
// of the ray. The scale is a power of two, so both multiplies are exact and the
// only rounding is in the subtract, an order of magnitude smaller than the
// quantization margin the host added to every box.
// origin_times_inv is the once-per-ray product q_origin * q_inv_direction that
// lets the slab test evaluate (plane - origin) * inv as a single fma, cutting
// six subtracts out of every node test.
struct PtQRay {
    float3 origin;
    float3 inv_direction;
    float3 origin_times_inv;
    float t_min;
    float t_max;   // world-space t limits
};

inline PtQRay pt_make_qray(PtScene scene, PtRay ray, float world_t_min, float world_t_max) {
    constant PtParams& params = *scene.params;
    PtQRay q;
    q.origin = (ray.origin - pt_v3(params.bvh_origin)) * float3(params.bvh_scale);
    q.inv_direction = ray.inv_direction * float3(params.bvh_inv_scale);
    q.origin_times_inv = q.origin * q.inv_direction;
    q.t_min = world_t_min;
    q.t_max = world_t_max;

// A node is two 16-byte vector loads: the scaled box minima, then the scaled
// maxima with the payload bit pattern in the fourth component. Both boxes are
// stored as float32 by the host, so the box needs no integer-to-float convert
// at all on the hot path; the payload is reinterpreted without arithmetic.
struct PtNodeView {
    PtQBox box;
    uint payload;
};

inline PtNodeView pt_load_node(PtScene scene, uint index) {
    const device float4* base = scene.nodes + 2u * index;
    const float4 lo = base[0];
    const float4 hi = base[1];
    PtNodeView view;
    view.box.lo = float3(lo.x, lo.y, lo.z);
    view.box.hi = float3(hi.x, hi.y, hi.z);
    view.payload = as_type<uint>(hi.w);
    return view;
}

// Leaf payload layout: bit 31 set, bits 8..30 the triangle start, bits 0..7 the
// triangle count minus one (the host build keeps every leaf at 256 or fewer).
inline bool pt_node_is_leaf(uint payload) {
    return (payload & PT_BVH_LEAF_BIT) != 0u;
}

inline uint pt_node_start(uint payload) {
    return (payload >> 8) & 0x7FFFFFu;
}

inline uint pt_node_count(uint payload) {
    return (payload & 0xFFu) + 1u;
}

// Ray/axis-aligned box slab test against a quantized box, run entirely in
// quantized coordinates. The two multiplications that turn world t limits into
// quantized ones are hoisted out of the traversal, and the plane-minus-origin
// product is a single fma against the ray's precomputed origin*inv, so a node
// test costs one convert, two fma, two min/max pairs and the compares per axis.
inline bool pt_qbox_hit(PtQBox box, float3 q_inv_direction, float3 origin_times_inv,
                        float t_min_q, float t_max_q) {
    const float3 t0 = fma(box.lo, q_inv_direction, -origin_times_inv);
    const float3 t1 = fma(box.hi, q_inv_direction, -origin_times_inv);
    const float3 lower = fmin(t0, t1);
    const float3 upper = fmax(t0, t1);
    const float entered = fmax(fmax(lower.x, lower.y), max(lower.z, t_min_q));
    const float exited = fmin(fmin(upper.x, upper.y), min(upper.z, t_max_q));
    return entered <= exited;
}

// Same test, but also reports where the ray enters the box, so the closest-hit
// traversal can visit the nearer child first without a second test.
inline bool pt_qbox_hit_entered(PtQBox box, float3 q_inv_direction, float3 origin_times_inv,
                                float t_min_q, float t_max_q, thread float& entered_out) {
    const float3 t0 = fma(box.lo, q_inv_direction, -origin_times_inv);
    const float3 t1 = fma(box.hi, q_inv_direction, -origin_times_inv);
    const float3 lower = fmin(t0, t1);
    const float3 upper = fmax(t0, t1);
    const float entered = fmax(fmax(lower.x, lower.y), max(lower.z, t_min_q));
    const float exited = fmin(fmin(upper.x, upper.y), min(upper.z, t_max_q));
    entered_out = entered;
    return entered <= exited;
}

    return float3(f.x, f.y, f.z);

// Moller-Trumbore against the precomputed origin/edge1/edge2 form, double
// sided because the glass shows backfaces.
inline bool pt_ray_triangle(device const PtTri& tri, float3 origin, float3 direction,
                            thread float& t, thread float& u, thread float& v) {
    const float3 e1 = pt_v3_16(&tri.edge1);
    const float3 e2 = pt_v3_16(&tri.edge2);
    const float3 p = cross(direction, e2);
    const float det = dot(e1, p);
    if (fabs(det) < 1e-12f) {
        return false;
    }
    const float inv_det = 1.0f / det;
    const float3 s = origin - pt_v3_16(&tri.origin);
    u = dot(s, p) * inv_det;
    if (u < 0.0f || u > 1.0f) {
        return false;
    }
    const float3 q = cross(s, e1);
    v = dot(direction, q) * inv_det;
    if (v < 0.0f || u + v > 1.0f) {
        return false;
    }
    t = dot(e2, q) * inv_det;
    return t > 1e-5f;
}

inline bool pt_ray_plane_y(float3 origin, float3 direction, float height, thread float& t) {
    if (fabs(direction.y) < 1e-9f) {
        return false;
    }
    t = (height - origin.y) / direction.y;
    return t > 1e-4f;
}

// Rectangle spanned by light_u/light_v around light_center, seen only from the
// emission side (a one-sided emitter).
inline bool pt_ray_light_rect(constant PtParams& params, float3 origin, float3 direction,
                              thread float& t, thread float3& point) {
    const float3 normal = pt_v3(params.light_normal);
    const float denom = dot(direction, normal);
    if (denom > -1e-9f) {
        return false;
    }
    const float3 center = pt_v3(params.light_center);
    const float candidate = dot(center - origin, normal) / denom;
    if (candidate <= 1e-4f) {
        return false;
    }
    const float3 hit_point = origin + candidate * direction;
    const float3 delta = hit_point - center;
    const float su = dot(delta, pt_v3(params.light_u));
    const float sv = dot(delta, pt_v3(params.light_v));
    if (fabs(su) > params.light_half_u || fabs(sv) > params.light_half_v) {
        return false;
    }
    t = candidate;
    point = hit_point;
    return true;
}
