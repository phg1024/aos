Phase 9 Report

aos-tui --workflow can now run a whole multi-agent workflow. The entry agent stays interactive. The agents it delegates to run through the same engine as aos run --workflow, and a live progress view shows their work.

What Was Done

  • agentflow.Engine.DelegateHandler(spec, req, agent, onChild) exposes the delegation logic that runAgent used to keep inline. Any runtime.AgentRuntime can now delegate the way the engine does: allowed_agents checks, the one-active-child-per-agent rule, and the delegate/start/exit/delegate_result trace events.
  • inference.BackendConfig now carries CompactRatio (from AOS_COMPACT_RATIO, default 0.8) and has a CompactionPolicy() method. aos run and aos-tui both use it. The TUI previously ignored AOS_LLM_CONTEXT_WINDOW.
  • render.WorkflowProgress builds the delegation stack from engine trace events and renders transcript lines and a status row.
  • render.FooterBar can pin a second row above the status row. Each redraw is one write, so a once-per-second ticker can keep the elapsed time moving during long model calls without interleaving with streamed output.
  • cmd/aos-tui in workflow mode connects the engine's delegation handler, the context-window compaction policy, and the progress view, and mirrors the entry agent's own tool calls into the progress row.

Decisions Made

  • The entry agent stays interactive, and only delegated agents run to completion on their own. This keeps the TUI's conversation model and reuses the engine unchanged. A run in the TUI and a run from aos run produce the same child processes, artifacts and trace events.
  • Steps are counted per action (tool call, delegation or message), matching what max_steps limits in the runtime. The entry agent's count resets each turn, because max_steps applies to each Run/Resume call.
  • finished counts delegated runs only. The entry agent's end-of-turn is not counted.
  • A delegation to an agent outside allowed_agents is still a runtime error rather than a recoverable tool error, the same as in aos run.
  • The TUI hands its message bus to the engine. Child agents use it only if they choose to send messages. aos run leaves it nil.

Known Gaps

  • No way to cancel a delegated run except Ctrl-C, which ends the whole TUI.
  • Delegated agents' results are printed as one-line summaries. Nothing can be expanded or collapsed.
  • /recover does not feed the progress row.
