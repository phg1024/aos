Issues Encountered And Resolved

  • A fully live writer agent looped on write_file after success. This was first mitigated by strengthening the generic backend contract to require an exit after a successful write.
  • Fully live coordinator agents were still fragile because they had to emit strict control JSON. The mini-project harness was then adjusted to use deterministic coordinators and deterministic writers while keeping the substantive synthesis, extraction, and review agents live on the local model.
  • The first scripted coordinator version counted delegate completions by text summary, which caused repeated writer spawns when a writer returned no message text. This was fixed by tracking delegate agent IDs instead.

Decisions Made

  • For the current milestone, orchestrators and I/O specialists are deterministic, while the semantic agents remain live. This matches the project goal better than forcing fragile control JSON out of every live agent today.
  • The final live suite demonstrates that review is optional workflow behavior: reviewed-merge includes a review agent because the workflow asks for one, not because AOS enforces it.
