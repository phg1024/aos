- Acted on:
  - The mechanism went into the shared log, the WM and the final report.

  - pid-000012 spent Experiment B (#48-#62) implementing the skip that round 3 had claimed was already there.
- Confidence: medium-high. The recorded mechanism is contradicted by the code the agent itself wrote. The measured 6/8-pair win is real, but its stated cause is false. This is an implementation slip rather than a recall failure, which is why it is not rated high.
