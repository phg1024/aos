aos-tui: Keyboard Picker for /resume

/resume listed every saved session, including the one the TUI was already in, and switching meant typing /resume N. Now /resume opens a picker. The arrow keys, j/k or a session's number move the selection, Enter switches to it, and Esc or q cancels. The current session is not offered.

Result: 3 new tests pass, the session-list test is updated, and go test -buildvcs=false ./... passes. A drive of the built binary in a pseudo-terminal opened the picker, moved down one row, and switched sessions on Enter. In that drive, the current session was absent from the list.

What Was Done

  • internal/tui/render/pick.go: the picker's key handling and layout. The selected row is kept in view in a short terminal, with "↑ N more" and "↓ N more" rows for the rest.
  • pick_termios.go: the terminal loop. It uses the same raw mode as the line editor, hides the cursor while picking, and clears the picker when it closes. pick_other.go reports the picker unavailable on other platforms.
  • lineedit.go: a lone Esc decodes as its own key. The line editor ignores it, as before.
  • cmd/aos-tui/main.go: /resume filters out the current session with otherSessions, then opens the picker. Without an interactive terminal it prints the numbered list. /resume N and the list number only the other sessions. The row format is shared by the list and the picker (sessionRow).
